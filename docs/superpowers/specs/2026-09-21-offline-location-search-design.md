# 离线地点搜索设计

## 目标

移除第三方地点搜索接口。地点输入只检索随小程序发布的离线地点库；本地未收录的地点通过微信地图选点处理。

## 数据

- 浙江及上海、江苏、安徽、江西、福建重点覆盖。
- 全国补充经典山岳、湖泊、草原、海岸和星空观景地。
- 每个地点可配置 `keywords`，用于别名、主峰和常用简称检索。
- 坐标使用 WGS-84，海拔为观测点近似值；地图选点保持原有流程。

## 交互

- 搜索输入即时匹配全部离线地点，不受当前分类限制。
- 空输入时继续展示“杭州周边 / 浙江名山 / 全国经典”分类。
- 移除远程搜索按钮和加载状态。
- 无匹配结果时展示“本地暂无，使用地图选点”操作。

## 质量保障

- 将搜索提取为纯函数。
- 测试名称、行政区、别名、空查询和无结果行为。
- 验证页面不存在地点网络请求。
